Trabajo Práctico Semana 3: Automatización de Calidad y
Blindaje

Objetivo: Automatizar la auditoría de calidad mediante tooling profesional y generar
evidencias inmutables para la integración.

   1.​ Configuración de un Pre-commit Hook: Configura un script local de pre-commit
       hook que ejecute de forma secuencial y obligatoria: Formatter, Linter y la suite
       de pruebas unitarias. Explica qué ocurre específicamente en la consola si uno
       de estos controles detecta un fallo y por qué esto protege la rama principal.​


   2.​ Auditoría Estática: A partir de un código fuente que presenta baja calidad
       (duplicaciones, alta complejidad ciclomática y dependencias desactualizadas),
       utiliza las métricas de análisis estático para identificar los puntos críticos.
       Propón una estrategia de refactorización que permita reducir la complejidad y
       asegurar la seguridad de las dependencias.​


   3.​ Informe de Calidad en Verde: Consolida todas las evidencias generadas en los
       trabajos prácticos anteriores en un único Informe de Calidad en Verde. Tu
       informe debe incluir: el enlace trazable entre el Pull Request y el Issue, los logs
       de ejecución del pre-commit hook, el reporte analítico de cobertura de código y
       el diagnóstico final de análisis estático, certificando así que el desarrollo es
       apto para su integración.
